## 关于我

我专注于把 AI 能力做成真正可用的产品和工具，主要关注：

- 具备记忆、工具调用、任务调度和长流程执行能力的 AI Agent，并关注插件生态与工具分发
- 可靠的 Agentic RAG：查询理解、路由、检索、工具循环与引用溯源
- 本地优先的应用，以及 Python 自动化工具
- Linux、Docker 和自托管服务在真实场景中的实践

项目会持续放在 GitHub 主页的 Pinned 区域，开发过程中的设计思考和踩坑经验则记录在[博客](https://blog.20061107.xyz/)里。
